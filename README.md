**⚛️ Quniverse**
**An AI-powered, interactive learning roadmap that makes quantum science approachable — starting with shared foundations, then branching into specializations like quantum computing and cryptography.**

🔗 **Live demo:** quniverse.vercel.app

💡 **The Problem**
Quantum science is one of the most exciting and rapidly growing fields today — but it's also one of the hardest for beginners to break into. Most learners hit the same wall: concepts like superposition and entanglement are thrown at you abstractly, with no clear starting point and no sense of how topics connect. A lot of people bounce off quantum computing entirely, not because it's impossible to learn, but because there's no beginner-friendly path through it.

🎯 **The Idea**
Quniverse solves this by treating quantum education as a structured roadmap, not a wall of theory:
Start with shared Foundations — 10 interactive modules covering the core ideas every specialization and then branch into a specialization — once the base is built, pick a domain:

✨ **Features**
🧭 Visual learning roadmap — the whole subject mapped out, with live status badges per domain 
🎮 Real interactive simulations — drag a 3D Bloch sphere, run a live double-slit interference experiment, and more
🤖 AI-powered explanations at your level — every module lets you toggle Beginner / Intermediate / Show me the math
💬 Ask-the-Tutor chat on every topic
🧠 Auto-generated quizzes — a fresh 3-question check for understanding, generated on demand
📊 Persistent progress tracking — see how many modules you've explored, saved across visits
🎯 "Why Quantum Matters" page — real stats on job growth, salaries, and where quantum is used today

🛠️ **Tech Stack**
=> Frontend: Vanilla HTML, CSS, and JavaScript 
=> 3D Visualizations: Three.js (Bloch sphere renderings)
=> AI: OpenAI API
